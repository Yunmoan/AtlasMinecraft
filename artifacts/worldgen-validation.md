# 普通世界生成验证（2026-10-01，树木实现前的版本）

后续树木实现及最新可执行文件的验证见 [tree-worldgen-validation.md](tree-worldgen-validation.md)。本页的构建哈希属于前一版本。

已更新根目录 `atlas.exe` 和 `atlas-test.exe`。Atlas 的运行时使用纯 Go，不调用 Java 或原版 JAR。

## 本轮实现

- 默认普通世界可从空目录创建，并按保存的种子生成缺失区块。
- 接入噪声、水体、矿脉、三维群系、地表和洞穴，以及矿物、森林岩石、蓝冰、黏土/砾石圆盘装饰。
- 写入 Java 1.21.1 的 `level.dat`、Anvil 区块、群系、高度图和流体后处理位置。
- 装饰按固定顺序回放邻区块，在临时地形上运算，只保存目标区块；并行生成、重复请求和探索顺序不会覆盖已有编辑。
- 修复装饰随机数调用顺序、出生区块重复预加载，以及重复开始或迟迟不结束的区块批次。增加控制台 `stop`，执行保存并退出。

## 仍未完成

树木及其余装饰、结构起始/引用、下界、末地和原版出生点搜索仍未实现。新普通世界明确关闭结构生成，并在元数据和区块中记录未实现的特征。固定顺序的跨区块装饰尚未证明与原版的邻区块执行顺序完全等价，因此不声明完整世界与原版逐方块一致。
