# 背包持久化与基础交互修复

日期：2026-10-01。Minecraft Java 1.21.1 / protocol 767。运行时保持纯 Go、标准库；Java 仅用于开发验证。根目录程序已更新为本报告对应版本。

## 问题与修改

原实现只保存玩家位置和飞行状态，快捷栏仅缓存方块类型，没有保存和恢复完整 Inventory。物品数量、非方块物品、组件、盔甲及副手不能依靠这个缓存持久化。方块放置流程也缺少多种使用、支撑和邻居规则。

- 新增完整物品堆解析与保存：物品 ID、数量、收到的组件 patch、嵌套物品；支持主背包、快捷栏、盔甲、副手、选中槽，以及临时光标/合成输入。入服发送恢复后的 46 槽内容与选中槽。
- Java `playerdata/*.dat` 写入标准 Inventory 槽位，同时保留原文件其他字段。自动保存和退出保存串行取快照/写盘，防止旧自动保存覆盖退出状态。组件数据在所有权边界深拷贝。
- 常见组件导入/导出包含名称、lore、自定义 NBT、耐久、附魔、染色、药水、自定义食物、迷之炖菜及嵌套容器。网络文本组件与存档 JSON 名称正确转换。额外保存原始网络数据和指纹，外部 Java 修改物品后不会用旧网络数据覆盖新内容。
- 修正协议表中三处 1.21.1 物品格式错误：药水没有后来版本的 customName；食物效果是完整 MobEffectInstance；using_converts_to 带 Optional presence boolean。对应格式由实际 JAR STREAM_CODEC 和原版生成的样本验证。
- 玩家菜单点击按服务端物品状态重放，支持拾取、分堆、合并、shift 转移、数字键/副手交换、克隆、拖拽分配与双击收集。忽略客户端伪造的 changedSlots 物品。物品组件及移除列表的排列顺序不会阻止相同物品堆叠；嵌套物品的原始存档字节不参与物品身份比较。
- 可见玩家收到主手、副手和四件盔甲装备，切换物品后同步更新。
- 空手可使用门、活板门、栅栏门、拉杆和按钮；铁门/铁活板门保留手动使用限制。门放置上下两半，点击任一半同步开关与碰撞。按钮有定时释放状态，尚无完整红石传播。
- 支持副手方块放置；墙火把转换为正确方块与朝向；灯笼、拉杆及按钮处理悬挂/附着朝向与支撑。门与附着方块失去支撑会清理，邻居传播可跨 region。
- 悬挂灯笼检查底面中心支撑；栅栏、铁栏杆和玻璃板更新连接/断开，避免树叶、屏障、南瓜及潜影盒等连接例外产生错误碰撞臂。放置检查所有玩家身体和门的上半部。

本版也包含此前已完成的出生区域预加载、多线程生成、入服加载事件、玩家移动同步及光照修复；相关说明见 [加载、实体与光照](../runtime-fix/validation.md) 和 [首次入服](../join-loading-fix/validation.md)。这些旧报告的哈希属于各自历史构建。

## 尚未完成

这次修复覆盖上述背包和基础交互，不能称所有实体/交互判断都已完成。完整红石与活塞运动、生物与掉落实体、实体攻击/使用、容器菜单、配方合成、扔出物品及生存机制仍有缺项；其余方块放置/更新、门铰链的全部邻居组合、位置/实体相关碰撞形状也尚未覆盖。

Atlas 保存的已接受组件 patch 能精确恢复；并非所有复杂组件都已实现标准 Java NBT 导入/导出。缺少导入 codec 时明确报错并保留原玩家文件。完整原版世界生成依然缺少结构、部分树木/特征、下界/末地和运行时维度等，详情见相关报告与 README。
