## 方法与复现

- 5 个种子为上表所列数值。主世界每种子 100 个区块，下界、末地各 50 个。
- 区块 X/Z 分别均匀抽样于 `[-1874983, 1874982]`，为生成邻区保留边界余量；坐标单位是区块。抽样器种子依次为 `20261107`、`20261108`、`20261109`。
- 开启结构生成。官方 JAR SHA-1 为 `59353fb40c36d304f2035d51e7d6e6baa98dc05c`，DataVersion 为 3955。
- 原版启动后关闭随机刻、冻结游戏，分批 forceload，并等待目标区块已加载；每批执行 `save-all flush`。
- Go 使用生产 `OverworldGenerator` / `DimensionGenerator`，主世界的 `BeehiveShuffleSalt=0`，无额外运行刻。
- 主世界比较 Y=-64～319；下界、末地比较完整建造高度 Y=0～255。下界上层空气也计入完整状态分母，另报排空指标。
- 从原版 Anvil 调色板独立解码状态，校验每块为 FULL、版本和种子正确，保存双方大端 uint16 数组及 SHA-256；Python 逐项复算计数、差异类型和哈希。
- 全部 15 组种子／维度的最终存档均与所用原版数组逐项核对一致。主世界实例在确认 flush 后停服收尾超时，结束进程后验证数据；下界、末地共 10 个实例均正常停服。后续工具保留最后一批加载票据至停服，并显式记录超时退出。

需要 Go、Python 标准库、JDK 21+ 和自行提供的官方 `jar/server.jar`；`JAVA_HOME` 可指定完整 JDK。从仓库根目录运行：

```powershell
python tools/worldgen/compare_random_worlds.py --dimension overworld --count 100 --output artifacts/random-world-comparison-2026-11-07
python tools/worldgen/compare_random_worlds.py --dimension nether --count 50 --output artifacts/random-nether-comparison-2026-11-07
python tools/worldgen/compare_random_worlds.py --dimension end --count 50 --output artifacts/random-end-comparison-2026-11-07
python tools/worldgen/summarize_random_comparison.py artifacts/random-world-comparison-2026-11-07
python tools/worldgen/summarize_random_comparison.py artifacts/random-nether-comparison-2026-11-07
python tools/worldgen/summarize_random_comparison.py artifacts/random-end-comparison-2026-11-07
```

仓库保留 [抽样清单、逐区块计数和数组哈希](../../testdata/worldgen/random_comparison_2026-11-07/)。CSV 可复算汇总计数；逐方块复算需本地 `artifacts/` 下的原始数组，或重新运行上述采样。原版 JAR、原版世界和大型数组不随仓库发布。继续运行会检查生成代码基线、当前原版数组和已保存数组哈希，不同生成代码必须使用新的输出目录。

## 差异与边界

- 主世界最差区块完整状态一致率为 99.046834%；常见差异涉及树叶、积雪、滴水石和洞穴装饰。
- 下界 12,598 个差异中，按 Go 区块群系标签归类：玄武岩三角洲 6,401（50.81%），诡异森林 3,002（23.83%），绯红森林 2,903（23.04%）。差异最多的 10 块贡献 89.01%；最差区块为种子 `4511451270791457643`、区块 `(-251498,365282)`，一致率 97.048950%，其 1,934 处差异均未改变空气／非空气占据。
- 下界重复采样时，种子 0 的 `(-939276,-624230)`、`(-501831,14849)` 在预跑与正式跑中，原版数组分别变化 609、1,494 个位置，Go 数组不变。报告使用正式跑的存档，未选择更吻合的参考结果；变化原因尚未定位，详见 [重复采样记录](../../testdata/worldgen/random_comparison_2026-11-07/nether-repeat-audit.json)。重采流程与坐标可复现，不保证原版每次输出的哈希均相同。
- 末地 179 块双方全空；另外 71 块的 434,356 个非空气位置也全部一致。均匀远区抽样未针对中央主岛或末地城定点加样。
- 这些是当前抽样快照的逐方块结果，不证明所有区块、实体、方块实体 NBT、光照、生物群系或运行刻等价，也不代表一般的 tick 队列兼容性。既有搁浅沉船四条最终熔岩请求顺序差异仍保留严格失败断言，见 [沉船验证边界](shipwreck_runtime_reference_1.21.1.md)。
